# Snow

Нативный снегопад для Windows 10/11 x64 на C++20 и Win32. Версия 0.3.0 — предварительная: функциональное равенство Flake и длительная стабильность еще не подтверждены.

## Возможности в коде

- Пять погодных режимов, плавное изменение ветра/плотности, детерминированная физика.
- Накопление снега на видимых верхних границах окон и обычной панели задач, перемещение вместе с окном.
- Отслеживание WinEvent/DWM, фильтрация свернутых/скрытых окон и виртуальных рабочих столов, ограниченная модель перекрытий.
- Отдельные прозрачные overlay для физических мониторов, включая отрицательные координаты.
- Варежка, лопата, создание снежков из накопленного снега, катание с ростом, перенос и сборка снеговика из трех шаров в явно включаемом режиме.
- Оригинальные шестиугольные снежинки на переднем плане; мелкий снег остается легкими мягкими частицами.
- Трей, нативные настройки, локальный версионированный INI, автозапуск по выбору пользователя.
- Eco/Balanced/Quality, снижение FPS на батарее, при энергосбережении и дорогих кадрах, пауза при блокировке/полноэкранном приложении.
- GDI с premultiplied alpha по умолчанию; экспериментальный D3D11/DirectComposition с instancing.

Этот список описывает реализацию, а не приемку на всех Windows-конфигурациях. Проверки и ограничения перечислены в [docs/ENGINEERING_EVIDENCE.md](docs/ENGINEERING_EVIDENCE.md) и [docs/QUALITY_BAR.md](docs/QUALITY_BAR.md).

## Сборка и тесты

Windows 10 (1703+) / Windows 11, Visual Studio 2022 (Desktop Development with C++), Windows SDK и CMake 3.24+:

```powershell
cmake -S . -B build -A x64 -DBUILD_TESTING=ON
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
.\build\Release\Snow.exe
```

Сборка не требует скачивания сторонних C++ библиотек. MSVC runtime включен статически. В CI также собираются Debug, MSVC AddressSanitizer и статический анализ с предупреждениями как ошибками.

На Linux/macOS собираются только переносимая модель и ее тесты, без приложения:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug -DSNOW_SANITIZERS=ON
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

## Управление

Меню иконки трея: пауза, погода, производительность, инструменты, настройки и выход. Ctrl+Alt+F11 — пауза; Ctrl+Alt+F12 — выход. Если сочетание занято, доступно меню трея с клавиатуры Windows+B.

В обычном режиме клики проходят сквозь overlay. Режим инструмента включается вручную: левая кнопка очищает снег или создает фигуру. Escape, правая кнопка или меню трея возвращают обычный режим. При невозможности зарегистрировать Escape инструмент не включается; через 30 секунд бездействия он отключается автоматически. Для снежка/снеговика требуется накопленный снег. В режиме «Снежок» нажмите на сугроб для создания шара, затем тащите его по снегу: собранная масса увеличивает размер. Шар можно приподнять и отпустить над другим, равным или большим шаром. Три шара образуют снеговика с лицом. Нижние опоры зафиксированы; верхний шар можно снять. Вся фигура остается привязана к своему окну.

Перенос проходит только по видимому участку своего окна; через закрывающие окна снег не переносится. «Очистить накопленный снег» удаляет сугробы и фигуры. Уменьшение максимальной высоты применяется и к уже накопленному снегу.

Настройки: `%LOCALAPPDATA%\Snow\settings.ini`. Поврежденный файл или файл будущей версии не перезаписывается; приложение использует значения по умолчанию. Переименуйте такой файл перед сохранением новых настроек. Автозапуск хранится в HKCU и включается только пользователем.

## Рендереры и замеры

```powershell
.\build\Release\Snow.exe --renderer=gdi
.\build\Release\Snow.exe --renderer=d3d11
```

Для измерения активного снегопада в контролируемой среде добавьте `--benchmark`: этот явный диагностический режим отключает только автоматическую паузу поверх полноэкранного окна. Обычный запуск сохраняет ее. Профилировщик записывает реальное состояние/renderer и частоту native submissions первого монитора отдельно от целевого FPS.

D3D11 пока экспериментальный. При недоступности устройства используется GDI; переключение требует нового HWND. [Сравнение рендереров](docs/RENDERER.md) отделяет расчет размеров буферов от измеренных Private Bytes/Working Set и GPU memory. [Профилирование](docs/PROFILING.md) содержит воспроизводимые сценарии. Никаких гарантий 20–60 МБ RAM без замеров на целевой машине нет.

## Предварительная сборка

Успешный Windows CI прикладывает Snow.exe, portable ZIP, установщик для текущего пользователя и SHA-256. Установщик собирается Inno Setup 6, административные права и автоматическое включение автозапуска не нужны. Релизы автоматически не публикуются.

Перед стабильным выпуском обязательны интерактивные проверки Windows 10/11, разных DPI/мониторов, кликов/фокуса, Explorer restart, GPU recovery и 8-часовой прогон.
