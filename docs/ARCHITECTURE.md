# Snow — архитектура 0.2.0

## Компоненты

- `main.cpp`: разбор ограниченного набора CLI-флагов, DPI и безопасная граница запуска.
- `application.*`: RAII lifecycle, скрытый controller, tray, по одному overlay на физический монитор, системные события, настройки и явно включаемые инструменты.
- `scene.hpp`: общие физические координаты, прямоугольники, интервалы и компактные примитивы рисования.
- `core.*`: детерминированный xorshift, 120Hz fixed step, ограниченный пул частиц; SnowAccumulation и одномерные HeightField; version=1 INI parsing/validation.
- `performance_monitor.hpp`: измеренный CPU frame cost и гистерезис 60/30/15 FPS; сигналы питания/общей CPU загрузки поступают от Windows.
- `window_tracker.*`: out-of-context WinEvent, DWM bounds, IVirtualDesktopManager, поколения HWND, панели задач и отсечение перекрытий.
- `renderer.*`: persistent premultiplied-alpha GDI DIB baseline и opt-in D3D11/DirectComposition instanced quads; ресурсы принадлежат конкретному overlay.

UI/симуляция/рендеринг выполняются в одном UI thread. Это намеренное упрощение: нет межпоточных гонок геометрии и ресурсов. Дорогие кадры снижают FPS; недопустимые задержки должны подтверждаться профилированием, прежде чем вводить отдельный render thread. Блокирующих ожиданий и busy-wait в цикле приложения нет.

## Ресурсы и события

4096 частиц × 24 байта; не более 128 поверхностей, 2048 float-ячеек на поверхность, шаг 8px. Сцена ограничена 32768 примитивами. Фигуры ограничены 32 и принадлежат поколению поверхности. Эти значения описывают полезные данные, а не полный Working Set процесса.

Высота хранится в локальных координатах окна, origin остается в snapshot. Перемещение не меняет высоты; resize сохраняет существующие локальные ячейки и освобождает лишнее. Закрытые/свернутые/ушедшие с текущего рабочего стола поверхности удаляются; возвращенное окно начинает новое накопление. Уничтоженный HWND и изменение PID/TID не наследуют старую модель.

WinEvent доставляет coalesced wakeup без DLL-инъекций. Application ставит one-shot 50ms timer для reconciliation при перетаскивании; дополнительно состояние сверяется каждые 2 секунды. Ни EnumWindows-подобный обход, ни выделение поверхностей не выполняются каждым кадром.

Кадры планируются waitable timer (high-resolution на Windows 10 1803+), а UI использует MsgWaitForMultipleObjectsEx без spin loop. Пауза отменяет frame timer, скрывает overlay и сбрасывает остаток fixed step. Трекер и редкая сверка продолжают обслуживать системные изменения и восстановление. Смена погоды не пересоздает DIB/устройство/окна.

## Рендеринг и восстановление

На каждый монитор выделяется только его изображение; промежутки виртуального desktop не получают полноэкранного DIB. GDI baseline передает ULW_ALPHA. D3D candidate рисует ограниченный instance buffer без чтения кадра в CPU, но выделяет backbuffers/driver resources и не считается экономнее без A/B замеров.

При ошибке GPU native resources освобождаются; приложение пересоздает HWND и пробует GDI один раз. Ошибка GDI приводит к безопасному выходу. Повторяющегося retry loop нет.

## Ограничения

Прямоугольная консервативная модель перекрытий проверяет 96px полосу над краем; сложные формы/полупрозрачность могут исключать больше снега, чем требуется. Автоматически скрываемая панель задач остается без снега. Фигуры не являются физикой твердых тел и не бросаются между окнами. Идентификация игр основана на полноэкранной геометрии, не на чтении других процессов.

Настройки не содержат путей чужих окон, заголовков или персональных данных; сетевых функций и телеметрии нет. Autostart меняется исключительно через явный checkbox пользователя в HKCU.
