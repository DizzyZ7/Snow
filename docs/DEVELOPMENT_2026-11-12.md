# Snow 0.3.0 — реализация и проверки

Продолжение PR #1, без дублирующей ветки и копирования кода/ресурсов Flake.

Приоритет этого цикла: завершить исправления нативных циклов Windows, сделать снежки управляемыми объектами и проверить реальный ввод/визуальную композицию. Память остается ограничена существующими лимитами; не добавлены UI runtime, физический движок, сервер или база данных.

- [x] Катание, рост из массы сугроба, перенос и сборка из трех шаров; отсутствие циклов и переносов через невидимые участки.
- [x] Немедленное применение высоты к старым сугробам и полная очистка фигур; ограниченное копирование интервалов snapshot.
- [x] Оригинальные снежинки shape=2 в GDI и D3D11 без дополнительных текстур/буферов; небольшая популяция переднего плана.
- [x] Реальная мышь: через видимый снег в другой процесс, перехват только в режиме инструмента и восстановление после выхода, без захвата фокуса.
- [x] Проверка нативных счетчиков на реальной CPU-работе, измерение GDI/D3D11 на одном runner.
- [x] Release/Debug/MSVC ASan/static analysis/Linux sanitizers; portable/установщик/SHA-256, установка/удаление.

Пункты отмечаются только после выполненных проверок. Windows Server CI не заменяет ручные Windows 10/11, mixed DPI, hotplug и 8-часовой тест. Стабильный релиз и равенство Flake не объявлены.

Локально выполнены GCC14 C++20 / -Wall -Wextra -Wpedantic -Werror и AddressSanitizer/UBSan (локально detect_leaks=0 из-за ptrace): 2961 проверка прошла. Независимый обзор выявил пропущенное освобождение capture на WM_CANCELMODE; обработчик исправлен, в native app smoke добавлено воспроизведение. Windows CI 43227509224 выполнил все 10 CTests в Release/Debug/MSVC ASan, а также /analyze, упаковку, установку и удаление. Все прошли; Linux sanitizer/leak CI тоже прошел.

Измеренное сравнение GDI/D3D11 за 20 секунд на одном runner и исходные CSV записаны в ENGINEERING_EVIDENCE.md. Пятиминутный GDI прогон публикует отдельные CSV/metadata в CI artifact; более длительная аппаратная приемка остается обязательной.
